# 🤝 Contributing to NavHat PRO

We welcome contributions from developers, hardware engineers, assistive technology researchers, and open-source enthusiasts!

---

## 🛠️ How to Contribute

1. **Fork the Repository**:
   Click **Fork** on the top right of the [NavHat-PCB-Design repository](https://github.com/krishnendukoley2007-arch/NavHat-PCB-Design).
2. **Clone your Fork**:
   ```bash
   git clone https://github.com/<your-username>/NavHat-PCB-Design.git
   cd NavHat-PCB-Design
   ```
3. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/awesome-assistive-feature
   ```
4. **Follow Code Quality Standards**:
   - Firmware: Clean C++ formatted with clang-format or Arduino style guide.
   - Python: Clean, PEP8 compliant code with type annotations.
   - Hardware: Autodesk Fusion 360 / KiCad design rules verified before submitting PR.
5. **Commit & Push**:
   ```bash
   git commit -m "feat: add adaptive night vision lighting"
   git push origin feature/awesome-assistive-feature
   ```
6. **Open a Pull Request**:
   Describe your changes, screenshots / hardware validation photos, and testing steps.

---

## 🐞 Reporting Bugs & Requesting Features
- Open an issue in the **GitHub Issues** tab.
- Provide full hardware specs, ESP32 serial logs, and Python terminal output.
